## 👨‍💻 About Me

I'm a Full Stack .NET Developer based in Egypt, focused on building web applications with ASP.NET Core and C# on the backend. I care about writing code that is not just functional but also clean, secure, and built to scale — which is why Clean Architecture and SOLID principles are at the center of how I structure my projects.

On the frontend, I work with Angular, TypeScript, and modern responsive UI practices to make sure the applications I build feel as solid on the client side as they are on the server. I enjoy the process of turning a real-world requirement into a well-organized, high-performance system, and I'm constantly digging deeper into software architecture and design patterns to get better at that.

I'm a continuous learner at heart — most of my free time goes into reading about Microsoft technologies, experimenting with new patterns, and refining how I approach problem solving. Always open to collaborating on interesting backend or full-stack work.
